# План зарплаты

Автоматический режим повторяет расчёт листа «ПЛАНЫ» из предоставленного
«Калькулятор_зарплаты_реалистичные_планы.xlsx». Он строит план на весь месяц,
а не прибавляет месячный план к уже зарегистрированным продажам.

1. Оклад = часы × ставка города. Нужный торговый бонус = max(0, цель − оклад − админ).
2. Коэффициент = вручную заданный мультипликатор × сезонность выбранного месяца.
3. Из нужного бонуса вычитается премия за фиксированные месячные объёмы золота,
   Mixx и кредитных заявок. Остаток распределяется: SIM 35%, аксессуары 30%,
   смартфоны 10%, услуги 20%, MNP 5%. Доли редактируются, сумма должна быть 100%.
4. Для каждого направления объём округляется вверх и ограничивается пределом:
   SIM 3/смену, аксессуары 3500 ₽/смену, смартфоны 15000 ₽/смену,
   услуги 1500 ₽/смену, MNP 8/месяц. Пределы редактируются.
5. Прогноз = оклад + админ + сумма премий по объёмам × коэффициент.
   Если цель не достигнута, показывается недобор. Неиспользованные доли
   автоматически между направлениями не перераспределяются — как в Excel.
6. Кредитный оборот = кредитная доля смартфонов + аксессуаров + услуг +
   заявки × страховка на заявку. Это справочная часть оборота, она не прибавляется
   к продажам и не приносит вторую премию. Заявки оплачиваются только в ноябре 2026.

Настройки сохраняются для сотрудника и месяца. Часы и число смен всегда берутся из блока «Рабочее время».
В плане они доступны только для просмотра и обновляются при изменении рабочего
времени. Старые отдельные значения часов и смен в настройках плана не используются. Пустые ставки берутся из категории города; SIM по умолчанию —
High Bundle ТП, золото — 3 месяца, абонемент — Mixx. Ставки можно переопределить
для плана, не меняя фактический расчёт. Мультипликатор плана задаётся отдельно
от фактических KPI. Налоги и удержания не рассчитываются.

Ручной режим сохраняет прежний способ: произвольные дополнительные показатели
прибавляются к текущей расчётной зарплате. Старые ручные строки не удаляются
при переключении режима.

Проверки из корня репозитория:

```sh
node tests/calculator.test.cjs
node tests/realistic-plan.test.cjs
```

Числовой пример из Excel сохранён без ФИО в `tests/fixtures/realistic-plan.json`:
ноябрь 2026, Березники, цель 50000 ₽, 178 часов, 20 смен, множитель 1, админ 0.
Прогноз 42640 ₽, недобор 7360 ₽, кредитный оборот 220000 ₽.

## Остаток плана и темп

Таблица сопоставляет месячный план с дневником: факт, остаток и нужный объём
на оставшуюся рабочую смену. SIM объединяются по платным тарифам (включая
«Бустер»), остальные направления сопоставляются с указанным продуктом.
Перевыполнение даёт нулевой остаток, без отрицательных значений.

Отработанные смены считаются по дням с часами или операциями; комментарий сам
по себе сменой не считается. Число можно уточнить вручную, в том числе ввести 0.
Остаток смен = max(0, план смен − отработанные). Дневной темп округляется вверх.
При отсутствии оставшихся смен и наличии недобора выводится сообщение,
а не деление на ноль.

Заработано по дневнику = внесённые часы × ставка + фактическая итоговая премия
с текущими KPI и административными выплатами. Общие месячные часы из формы
не считаются уже отработанными. Нужный заработок в день = остаток до желаемой
зарплаты / оставшиеся смены; сумма включает оклад и премию. Дневной ориентир показывается только для желаемой зарплаты.
Остаток до реалистичной прогнозной зарплаты плана показан отдельно.
